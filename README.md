# todoable

todoable은 외부 사건이나 정기 일정으로 생긴 작업을 사용자 정의 완료조건까지 실행하는 개인용 로컬 도구다. 입력 중복, 같은 자원의 동시 사용, 유한 반복, 중단 뒤 결과 불명을 관리한다. 작업 명령과 완료검사는 사용자가 제공한다.

Task 등록·버전 갱신, 입력 접수, 일정, 데몬 실행, 중단 복구, 수동 해소와 취소를 구현했다. `task show`, `run show`, `status`는 사람용 출력과 `--json` 조회를 제공하고, `logs`는 저장 로그와 `--follow` 조회를 제공한다. CLI의 접수 성공은 저장 성공이며 실제 작업은 별도 `daemon`에서 실행된다.

아직 출시 완료 상태는 아니다. 일부 로컬 시나리오와 실제 이슈 수정·자료 변환·외부 게시를 검증하는 실환경 시나리오가 남아 있다. 검증된 기능과 남은 범위는 [남은 작업](docs/roadmap.md)에 기록한다. 요구사항 문서에는 미완료 계약도 포함되어 있다.

개발을 시작하려면 [기여 가이드](CONTRIBUTING.md)의 도구 준비와 빠른 검증을 따른다. 제품의 흐름과 완료 기준은 [사용자 시나리오](docs/scenarios.md), 명령·입력·설정·예시는 [요구사항 참조](docs/requirements.md), 구현 순서는 [남은 작업](docs/roadmap.md)에서 확인한다.

v1의 목표 환경은 Linux amd64·arm64, 단일 호스트·단일 사용자다. Go 실행 파일과 로컬 SQLite를 사용하며 외부 입력 수집기와 특정 에이전트 제품의 전용 연동은 포함하지 않는다.
