# v1 명세 이관 대조표

2026-09-11에 루트의 단일 명세를 godev 문서 위계로 이관했다. 제품 계약 버전은 1.0이며 제품 동작을 변경한 이관이 아니다. 기존 파일은 아래 보존 대조 후 삭제했다.

[사용자 시나리오](scenarios.md)는 완료 판정의 최상위 규범, [요구사항](requirements.md)은 상세 계약·기본값·예시의 참조다. 원문의 1~14절은 절 번호와 본문을 그대로 보존했다. 15절의 27개 출시 검증 행은 순서대로 SC-01~SC-27로 전개했으며 참조 목록도 요구사항에 남겼다. 세 가지 실사용 검증은 SC-28~SC-30이다.

바뀐 안내 문구는 문서 제목, 유일한 현재 명세라는 서문의 문서 위계 안내, 15절의 완료 판정 안내, 마지막 버전 변경 안내다. 의미를 축약해 계약을 지우지 않았다.

## 읽는 경로

README는 제품 목적과 현재 구현·검증 상태를 설명한다. CONTRIBUTING은 도구 준비·검증·리뷰를 안내한다. architecture는 계층과 구현 경계, roadmap은 실제 남은 작업을 기록한다. AGENTS.md는 에이전트의 작업·보고 규칙을 담는다. 이 문서는 원문 출처를 추적할 때만 필요하다.

문서 이관과 골격 검증 성공은 제품 구현 완료를 뜻하지 않는다. 각 SC의 테스트는 미구현 표식을 제거하는 것만으로 완료되지 않으며 실제 흐름과 모든 검증 단정문을 구현해야 한다.
